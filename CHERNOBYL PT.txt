|------------------|

npm install

npm run electron:dev

npm run dev
acessar rede local via nagevador ou abrir via index.html na pasta "dist"

Para atualizar o site Web (se a pasta já estiver configurada):
npm run build
firebase deploy --only hosting

Para gerar o instalador atualizado:
npm run build:electron
O instalador será gerado na pasta: dist_electron

postar atualização:
npm run publish

Para atualizar basta trocar a versão no package, rodar o npm run build e depois npm run pubish
